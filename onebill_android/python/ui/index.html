Safety & setup

Settings

11
Your data is stored on this PC only.

Folder:
One automatic backup is made per day. Automatic backups and the safety copy made before a restore are always plain (not encrypted) and hold all your data, so keep this folder private. Only backups you make with a passphrase are encrypted. Copy backups to a USB drive or another disk too.

If you lose the passphrase the backup cannot be opened.
Google Drive backup (NOT TESTED with a real Google account)

You need your own Google "Desktop app" client ID (steps in GOOGLE_DRIVE_SETUP.md). OneBill can see only the files it uploads. The client ID, secret and sign-in are kept in a file on this PC, never in a backup.
